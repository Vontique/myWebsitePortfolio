# My Portfolio Website

A personal portfolio website developed and deployed as part of my 80-hour work immersion at **Techstacks**.

## 🌐 Live Demo
Check out the live website deployed on Vercel: [vonvon-portfolio.vercel.app](https://vonvon-portfolio.vercel.app/)

## 🛠️ Built With
* **HTML5** - For semantic markup and page structure
* **CSS3** - For custom layout styling and responsive design
* **Vercel** - For production hosting and deployment

## 🚀 About the Project
This project was created during my work immersion program at Techstacks to demonstrate practical frontend development skills, responsive design principles, and modern web deployment workflows.

## 📂 File Structure
* `index.html` - Main landing page markup
* `styles.css` - Custom style sheet for layout and visual styling
* `background_image.jpg`, `picture.jpg`, `logo.png` - Visual media assets used across the portfolio
